# BusGo - Bus Ticket Booking Website

## Project Overview
BusGo is a responsive online bus ticket booking website designed to make bus reservations simple and convenient. Users can search for buses, select seats, enter passenger details, and complete their bookings through an easy-to-use interface.

## Features
- Search buses by source, destination, and travel date.
- Select between Semi-Sleeper and Sleeper buses.
- Interactive seat selection.
- Seat availability status (Available, Selected, Booked).
- Passenger details and booking process.
- Payment and booking confirmation screens.
- QR code ticket confirmation.
- Responsive and user-friendly interface.

## Seat Configuration
- Semi-Sleeper: 50 seats.
- Sleeper: 30 seats (15 Lower Deck and 15 Upper Deck).
